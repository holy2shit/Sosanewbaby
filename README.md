# Телеграмм Бот
TextCleanerBot - Telegam бот для работы с текстом
Простой и полезный Telegram бот для быстрой обработки текста: очистка от лишних пробелов, подсчёт статистики и смена регистра.
# Возможности
- Убрать пробелы и переносы - очищает текст от лишних пробелов, табуляций и переносов строк
- Посчитать слова и символы - показывает количество символов, слов и предложений
- Изменить регистр - преобразует текст в верхний или нижний регистр
# Технологии
- Python 3.10+
- python-telegram-bot - библиотека для создания Telegram ботов
- re - регулярные выражений для обработки текста
# Установка и запуск
1. Зайдите в cmd и впишите "pip install python-telegram-bot
2. Получите токен бота у @BotFather в телеграмме
3. Замените "TOKEN" в файле bot.py на свой
4. Запустите бота:
   python bot.py
# Как использовать
1. Отправьте боту команду /start
2. Отправьте любой текст
3. Выберите действие на клавиатуре:
- Убрать пробелы и переносы - очистка текста
- Посчитать слова и символы - статистика
-  В ВЕРХНИЙ регистр / в нижний регистр - смена регистра
